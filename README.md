# diy-hardware-radio

Radio production project involving custom PCB design, automated prototyping fabrication, manual SMD assembly, and a tailored 3D-printed enclosure. The repository serves as a manufacturing portfolio to document the physical workflow of reverse-engineering a proven analog radio schematic, routing the traces for assembly in Altium/KiCad, sourcing the boards, hand-soldering surface-mount components, and modeling a custom mechanical housing in CAD.
